    limma¶

    edgeR and limma-voom differential expression, in Rust.

    NumPy in, polars out. Counts are (n_genes, n_samples) as in edgeR, every index is 0-based, and a design is a NumPy matrix or a polars frame whose column names become coefficient names.

    One call:

    >>> res = edge_rs.run_edger_ql(counts, design, feature_ids=genes, coef="treated")
>>> res = edge_rs.run_limma_voom(counts, design, feature_ids=genes, coef="treated")

    Step by step, as in edgeR and limma:

    >>> keep = edge_rs.filter_by_expr(counts, design=design)
>>> lib = counts.sum(axis=0)
>>> nf = edge_rs.calc_norm_factors(counts[keep], lib_size=lib)
>>> fit = edge_rs.glm_ql_fit(counts[keep], design, lib_size=lib, norm_factors=nf)
>>> edge_rs.top_tags(edge_rs.glm_ql_ftest(fit, coef="treated"))

    Every function that takes counts also takes a DgeList from make_dgelist, which carries lib_size and norm_factors and keeps the library sizes of the full matrix through a gene subset.

    voom ¶

    voom(
    counts: ndarray | DgeList,
    design: Design,
    *,
    lib_size: Vector | None = None,
    norm_factors: Vector | None = None,
    span: float = 0.5,
    adaptive_span: bool = True,
    prior_count: float = 0.5,
) -> Voom

    Log2-CPM with precision weights from the mean-variance trend, limma's voom.

    For a normalised expression matrix. To test, voom_lm_fit is the one-step route and handles structural zeros; lm_fit(v.e, design, weights=v.weights) is limma's classic two-step one.

    Parameters:

    Name Type Description Default
    counts ndarray | DgeList

    (n_genes, n_samples) raw counts, already filtered, or a DgeList.

    		 required
    design Design

    (n_samples, n_coef) design.

    		 required
    lib_size Vector | None

    Library size per sample. Defaults to the column sums.

    		 None
    norm_factors Vector | None

    Normalisation factors, multiplied into lib_size.

    		 None
    span float

    Lowess span, used only when adaptive_span is off.

    		 0.5
    adaptive_span bool

    Pick the span from the number of genes.

    		 True
    prior_count float

    Count added before the log.

    		 0.5

    Returns:

    Type Description
    Voom

    The Voom.
    References

    Law, Chen, Shi and Smyth, Genome Biology, 2014.

    top_table ¶

    top_table(
    fit: LinearFit,
    *,
    coef: int | str | None = None,
    feature_ids: Labels | None = None,
    number: int | None = None,
    sort_by: TableSort = "B",
    p_value: float = 1.0,
    lfc: float = 0.0,
    confint: bool | float = False,
) -> DataFrame

    The moderated t-test for one coefficient as a table, limma's topTable.

    The adjusted p-value is Benjamini-Hochberg over every gene, before number, p_value or lfc thin the table.

    Parameters:

    Name Type Description Default
    fit LinearFit

    The LinearFit, after ebayes.

    		 required
    coef int | str | None

    0-based coefficient or its name. None is the last one.

    		 None
    feature_ids Labels | None

    One id per gene of the fit. None uses the 0-based row.

    		 None
    number int | None

    Maximum number of rows. None keeps every gene.

    		 None
    sort_by TableSort

    Ranking column. "B" is limma's default.

    		 'B'
    p_value float

    Keep rows with adjusted p-value at most this.

    		 1.0
    lfc float

    Keep rows with absolute log2 fold change at least this.

    		 0.0
    confint bool | float

    Add a 95% interval on the fold change, or the level to use.

    		 False

    Returns:

    Type Description
    DataFrame

    feature_id, log_fc, ci_lower and ci_upper (with confint),
    DataFrame

    ave_expr, t, p_value, adj_p_value and b.

    Raises:

    Type Description
    ValueError

    If ebayes has not run, or on an unknown coefficient.
